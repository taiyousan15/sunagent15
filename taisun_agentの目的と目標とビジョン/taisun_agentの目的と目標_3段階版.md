# ⚡ 段階 1: 30 秒で分かるキャッチコピー

## 🌞 taisun_agent は、太陽のようにみんなを輝かせるシステム

Claude Code にインストールするだけで、  
**主婦でも社長でも会社員でも、「作りたいシステム」**を  
AI が**大企業レベルの品質**で**自動的に要件定義・開発準備**してくれます。

**対象**: 30〜60 代のあらゆる方（パソコン初心者 OK）  
**得意**: マーケティング・ビジネス・動画・画像

# 🕐 段階 2: 3 分で分かる Before / After

## 😩 Before（今の一般的な開発）

```
💭「こういうシステム作りたいな...」
     ↓
❓「要件定義って何？ どう進めるの？」
     ↓
📖 3 週間、ネットで調べても分からない
     ↓
⏰ 時間だけ過ぎて、結局諦める...
```

## 😊 After（taisun_agent を使うと）

```
💭「こういうシステム作りたい」と伝える
     ↓
🤖 AI が自動でリサーチして提案
     ↓
📋 大企業レベルの要件定義と SDD を自動作成
     ↓
🚀 開発準備がほぼ自動で完了
     ↓
🎉 やりたいことが実現できる！
```

> **SDD** = Spec-Driven Development（仕様駆動開発）。先に仕様を確定させてから開発する手法。

## 👥 誰のためのシステムか

| 使う人 | 困っていること | taisun_agent でどうなる |
|---|---|---|
| 🏠 主婦 | 家計管理アプリ作りたいが専門用語が難しい | 「こんなアプリ作りたい」と言うだけ |
| 💼 経営者 | 業務システム化したいが IT コスト高すぎる | 自社用システムの設計を AI が自動提案 |
| 📢 マーケター | 広告分析ツール欲しいが作れない | LP・広告・分析までパイプライン化 |
| 🏢 会社員 | 業務自動化したいが時間がない | 業務フローを伝えるだけで自動化案が出る |
| 🎨 初心者 | 何から始めていいか分からない | 入口から出口まで AI が伴走 |

## 💪 5 つの技術的強み

| 強み | 意味（素人向け） |
|---|---|
| 1️⃣ **費用抑制** | AI 利用料を最小化する仕組み |
| 2️⃣ **メモリ強化** | 過去の会話・作業を忘れない |
| 3️⃣ **エラー削減** | 問題が起きてもスムーズに復旧 |
| 4️⃣ **コンテキスト抑制** | 一度に扱える情報量を最大化 |
| 5️⃣ **目的忘却防止** | 作業中に目標がブレない仕組み |

# 📘 段階 3: 詳細（原点の完全版）

## 🎯 目的（なぜ作るか）

1. **Claude Code で素人や中級者でも様々なシステムを開発できるようにする**
2. **素人でも最初からインストールできるようにする**
3. やりたいことを実現するためのハブとして活用してもらう
4. 世の中の役に立つようなシステム開発をサポートする体制を整える

## 👥 対象ユーザーの詳細

- **年齢層**: 30 〜 60 代
- **職業**: パソコン初心者 / 主婦 / 会社員 / マーケティング事業者 / 経営者
- **IT スキル**: 初心者 〜 中級者
- **動機**: 「作りたいものがあるけど、技術の壁で諦めている人」

## 🤖 システムの動作フロー

1. ユーザーが **「やりたいこと」を伝える**
2. **リサーチシステム / リサーチ関連** が自動で提案
3. **要件定義・SDD** をプロ以上・大企業レベルで自動仕上げ
4. **開発準備をほぼ自動化**

## 🚧 解決したい課題

### 使う側の課題
- 要件定義・準備段階に多くの人が時間をかけすぎている
- 初心者には難しく感じる部分が多い

### 技術的課題（大量処理時に発生）
- API が止まる
- エラーが頻発する
- コンテキストが大量消費される
- メモリ不足で情報を忘れてエラーになる

## 🛠️ 5 つの改善項目（詳細）

| # | 項目 | 何をする |
|---|---|---|
| 1 | **費用を抑える仕組みを構築** | AI 呼び出しコスト削減、モデル自動切替 |
| 2 | **メモリを強化** | セッションをまたいで情報を保持する仕組み強化 |
| 3 | **エラーを減らし、発生時もスムーズ解決** | エラー検知・自動復旧フロー整備 |
| 4 | **コンテキスト消費を抑える構造** | 必要な情報だけ読み込む仕組み |
| 5 | **目的・目標・ルールを忘れない** | 作業中に方向性がブレない構造 |

## 💪 強化領域（特に得意なところ）

- **マーケティング**
- **ビジネス**
- **動画**（Shorts/Reels/LINE 風動画など）
- **画像**（LP 生成・AI 画像など）

## 🌟 長期ビジョン

- **世界トップクラス**のシステムにする
- **ディレクトリ構造・コードも美しい**最善形を構築
- **セキュリティ万全**、修正不要レベルの品質
- 開発者は**日々改善・機能追加**
- 使う側は**スムーズに使える**
- Claude Code / コーディング業界の**最新に常に追従**

## 🌞 名前の由来

**「太陽」**から来ています。

> 太陽のようにみんなを輝かせていけるようなシステムにしたい

## 🤝 類似プロジェクトとの関係

taisun_agent は **ハブ的な存在**です。

- 他の類似プロジェクトも taisun_agent にとって重要な存在
- 使う人にとってはそれぞれのスキルが必要となる
- taisun_agent を幅広く **どんな方でも受け入れて使えるように**
