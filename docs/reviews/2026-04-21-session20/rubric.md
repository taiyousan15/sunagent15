## 「壊さない度」判定（直交ルーブリック）

| 度合 | 条件 |
|---|---|
| 🟢 完全安全 | 新規追加のみ、既存 touch なし、behavior 変更なし |
| 🟡 軽微変更 | 既存 touch ありだが後方互換 100%、警告出力のみ |
| 🟠 破壊的（要周知） | behavior 変更あり、deprecation 期間 + warning 必須 |
| 🔴 破壊的（要合意） | 既存 workflow 破綻あり、ユーザー明示承認必須 |

Phase 4 の PR 候補リストは全件「壊さない度」を付与する。

## 判定手順（Phase 4 で Opus 4.7 が実施）

1. Phase 1-3 成果物を 1 件ずつ本ルーブリックに照合
2. 各指摘に `{theme: [n], severity: ..., 壊さない度: ..., 非技術者適合: ...}` のメタを付与
3. Pattern 10: 件ごとに実ファイルを開き、主張を再実測（サブ/Codex の数値は鵜呑みにしない）
4. 却下した指摘は `99-final-report.md §5` に理由付きで記録
5. 採用した指摘は `§3` の PR 候補リストに昇格
